# Stap voor Stap — Android-app (A1 en A2)

Nederlands leren (NT2), niveau A1 en A2, met uitleg in het Nederlands en Arabisch.
Deze branch (`nt2-a1-app`) staat los van de rest van deze repository.

- `www/` — de app (index.html, course.js voor A1, course-a2-*.js voor A2)
- `android/` — Capacitor Android-project
- `.github/workflows/android-apk.yml` — bouwt bij elke push de APK en zet die onder **Releases**

Installeren: open op de telefoon **Releases** → nieuwste `nt2-a1-v1.0.x` → `StapVoorStap-A1.apk`.
